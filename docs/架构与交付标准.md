# PaperCard Atelier（纸质笔记重新构建工作台）· 领导者架构规划与交付标准

> **制定者**：主智能体（Leader Agent）
> **协作模式**：主智能体负责制定核心需求、架构契约、阶段状态机、交付标准与自动化测试；调度多个 `pro` 与 `flash` 子智能体并行/接力完成工程模块构建与评估修正。
> **对标参考**：原生桌面架构的右上角一键复制提示词与本地工具闭环机制。

---

## 一、 核心设计哲学与三步主流程

本项目拒绝将纸质手写笔记简单变成“无法二次编辑的整页死图”，也拒绝把识别过程黑盒化为不可控的单次 OCR。我们汲取 **SkillAtelier** 的核心交互精髓——**“UI 右上角一键复制引导提示词 → 用户粘贴给任意多模态智能体 → 智能体调用本软件本地 CLI 工具逐页、逐区、分阶段落盘 → 现代化 UI 实时呈现并支持自由编辑排布”**。

### 核心三步骤（Three Core Steps）

1. **步骤一：导入纸张 & 右上角一键复制提示词（Import & One-Click Prompt Copy）**
   - 用户在界面导入单张或多张纸质手写扫描件/照片（支持跨页题目、一页多题、手写推导、几何/函数草图、思考随笔）。
   - 点击界面**右上角「复制识别指令」按钮**（`#copyAgentPromptBtn`），软件立即在本地生成任务索引 `task-index.json` 与进度快照 `progress.json`，并将一段包含**本地工具绝对路径、当前待处理任务索引、严格执行步骤约束**的完整提示词写入系统剪贴板，同时弹出 Toast 提示。
2. **步骤二：智能体调用本地 CLI 工具，严格按三阶段顺序推进（Agent-Driven Staged Execution）**
   - 用户将提示词手动发送给任意具备视觉与工具调用能力的 Agent。
   - Agent 调用本软件内置的本地 CLI 工具 `node "<project>/src/cli/noteTasks.js" <command> "<taskIndex>"`，**工具层通过状态机强约束执行顺序**，绝不允许跳步：
     - **阶段 2A · 逐页识别与分区 (`page_partition`)**：
       - 一个页面一个页面地识别。Agent 先观察整页纸张，提取页面摘要与原始排版网格，将页面划分为若干个独立的内容分区（`regions[]`），标记每个分区的归一化坐标 `bbox: {x, y, w, h}`、分区类型（`problem` 题目、`process` 过程、`key_step` 关键过程、`figure` 图形、`formula_block` 公式、`thought` 思考、`article` 文章）及字号层级。
       - 若包含图形，工具支持裁切保留**原始截图片段 (`cropPath`)**，并允许声明是否需要重新绘制及**重绘规则 (`redrawMode` + `redrawRule`)**。
     - **阶段 2B · 逐区生成可编辑卡片与即时关联推测 (`region_card_fill`)**：
       - 一个卡片一个卡片地填内容。针对当前分区的手写内容，Agent 将具体文字、LaTeX 公式、字号层级、图文对应关系完整转录进**可编辑卡片 (`editableContent` + `structureBlocks`)**。
       - 为卡片拟定明确标题 (`title`)。
       - 确认并写入**与本页其他分区的关联 (`intraPageLinks`)**（如归属某道题、承接某步推导、引用某张配图）。
       - 判断并写入**与其他页面的关联和推测 (`crossPageHypotheses`)**（如跨页解答续接、跨页定理引用及置信度说明）。
       - 写完一个分区后调用 `commit` 落盘，再调用 `next` 进入下一个分区，直到所有页面的所有分区卡片全部填完。
     - **阶段 2C · 全局关联确认、页面/画布排布与学科分类 (`global_synthesis`)**：
       - **只在所有卡片全部完成后才进入此阶段（最后考虑关联、排布与分类）**。
       - 汇总前序推测，确认最终的跨页续接关系与**题目 → 过程 → 关键过程 (`problemTrees`)** 结构树。
       - 计算并提交卡片在自由画布中的初始排布坐标 (`canvasLayout`)。
       - 将所有卡片按 **学科 (`subject`) → 科目 (`course`) → 章节 (`chapter`)** 进行分类组织，并归档思考、文章等内容 (`taxonomyAssignments`)。
3. **步骤三：优美的现代化 UI 展示与流畅动效（Modern UI & Fluid Transitions）**
   - 采用现代感纸墨美学（Warm Paper & Deep Ink + Glassmorphism 顶栏），支持深浅主题切换。
   - 提供三大核心视图，并具备 **页面 ↔ 卡片 ↔ 画布 之间的平滑切换动效（FLIP / 共享视觉锚点过渡）**：
     1. **原纸排版视图 (`page` view)**：左侧展示带交互式分区高亮框与原图裁切片段的手写原纸，右侧按原纸排版层级同步展示并可直接编辑对应卡片。
     2. **题解结构与学科分类视图 (`cards` view)**：按「学科 / 科目 / 章节」树状组织，清晰展示「题目 → 过程 → 关键过程」折叠链路、跨页标签、公式渲染、原始图形截图与重绘规则，支持随时增删改卡片内容。
     3. **自由画布视图 (`canvas` view)**：无限/自由二维画布，支持单选/多选卡片、拖拽自由排布、显示跨页与题解关联连线、一键按题解或章节重排。

## 三、 子智能体分工与领导调度方案

遵循用户要求：**不调用默认（inherit）子智能体，全部显式调度 `pro` 或 `flash` 子智能体协同构建**：

| 子智能体角色 | 模型选择 | 负责模块 | 交付物与评估标准 |
| --- | --- | --- | --- |
| **Core Engine & Agent CLI Architect** | `pro` | 本地存储、SkillAtelier 风格提示词生成器、外部 Agent CLI 状态机与种子数据 | 完成 `src/main/store.js`, `src/main/agentPrompt.js`, `src/cli/noteTasks.js`，确保 `status / next / commit / crop` 严格执行先分区→再逐卡填入并写关联推测→最后全局关联排布分类 |
| **Modern UI & Visual Motion Designer** | `pro` | 现代化 UI 界面结构、设计 Token、三大视图布局与切换动效样式 | 完成 `src/renderer/index.html`, `src/renderer/styles/tokens.css`, `src/renderer/styles/app.css`，确保右上角一键复制按钮、原纸对照、卡片层级与画布视觉达到高水准现代 UI |
| **Interactive Editor, Canvas & Server Developer** | `flash` | 前端交互逻辑、可编辑卡片、自由画布排布引擎与本地服务桥接 | 完成 `src/server.js`, `src/renderer/js/app.js`, `src/renderer/js/cardEditor.js`, `src/renderer/js/canvas.js`，打通前端操作与本地存储闭环 |

## 四、 交付与测试标准（Acceptance & Test Suite）

1. **提示词复制契约（对标 SkillAtelier）**：
   - 生成的提示词必须包含任务索引路径、可执行 CLI 命令（`status`, `next`, `commit`）、当前待识别页数，以及严格的三阶段执行指令。
2. **三阶段顺序不可逆约束**：
   - 任何页面未完成 `page_partition` 时，CLI 的 `next` 必须返回待分区页面，且拒绝提交 `global_synthesis`。
   - 任何分区未完成 `region_card_fill` 时，CLI 的 `next` 必须按序返回下一个待填卡片分区，且拒绝提前进入 `global_synthesis`。
   - 只有全部卡片均已填完且写入同页/跨页关联推测后，`next` 才进入 `global_synthesis` 阶段处理最终关联、页面/画布排布与学科/科目/章节分类。
3. **内容表达与可编辑性契约**：
   - 卡片内容必须包含可编辑文本 (`editableContent`)、结构化块 (`structureBlocks`)、字号层级 (`typography`) 与公式表达，绝不能仅是一张整页图片。
   - 图形区域同时支持保留原始截图片段 (`cropSvg` / `cropPath`) 和自定义重绘规则 (`redrawMode` + `redrawRule`)。
   - 支持 `题目 (problem) → 过程 (process) → 关键过程 (key_step)` 的归属链路，以及跨页内容续接 (`cross_page_cont`)。
4. **UI 视图与动效契约**：
   - 顶栏右上角具备「导入纸张」与「复制识别指令」按钮。
   - 支持「原纸排版」「学科卡片」「自由画布」三视图切换，画布支持多选卡片与自由拖拽重排，并具备平滑过渡动效。
